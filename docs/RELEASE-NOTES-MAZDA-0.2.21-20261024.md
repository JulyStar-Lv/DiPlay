# DiPlay Mazda EZ60 0.2.21 · 2026-10-24

基于上游 DiPlay 0.2.21，继续以 Mazda EZ60 适配预览版发布。
发布标签：`v0.2.21-mazda.20261024`。以下为相对 2026-10-20 预览版的更新。

## 音频播放与恢复

- 优化音频收包、解密和麦克风上行加密，减少重复的加密对象创建和临时内存分配。
- 当 iPhone 支持时协商 RTP 音频冗余恢复，补充包结构校验，以及乱序、重复包和丢包处理。
- 分离音频解码与播放写入，增加有界 PCM 队列、非阻塞写入和写入节奏控制，减少阻塞时的旧音频积压。
- 引入 Opus 软件解码和丢包补偿，分别设置音乐、通话、Siri、导航与提示音的等待及缓冲策略。
- 调整音乐启动、短片段播放和批量到包处理，改善较长收包间隔下的启动与补缓冲行为。
- 改进音频呈现时钟和播放速率微调，增加启动稳定期和速率渐变，减少将收包突发误判为时钟漂移的情况。
- 补充音频队列、丢包恢复、写入压力和时钟状态日志，方便继续排查播放延迟与进度偏差。

这些音频引擎改动位于公共模块，也会被从源码构建的其他应用复用；本次安装附件为 Mazda 版本。

## Mazda 默认设置

以下调整仅补齐未保存的设置，已保存的选择继续保留，相关音频选项在下次连接 CarPlay 时生效。

- 默认开启“禁用媒体按键音频焦点（实验性）”，初始化逻辑仅位于 Mazda 默认设置中，其他车型的通用默认值不变。用户已保存的关闭状态继续保留。
- 无线音乐缓冲默认设为 1000 毫秒；有线缓冲保留已保存值，未设置时为 300 毫秒。
- “缓冲音乐（实验性）”不再自动开启，未保存时默认关闭。此协议选项与上述无线音乐缓冲时长是两个独立设置。
- 未保存无线连接模式时，跟随通用的“车机热点”默认模式，不再自动预设 Wi-Fi Direct。已有连接模式和热点信息继续保留。
- MTK 解码优化仍在缺少设置时默认开启。
